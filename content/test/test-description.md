# 测试页面描述功能

## 📝 测试目标

这个页面用于测试 Quartz 的 `description` 页面描述功能。

### 期望结果

- **描述内容**: 应该出现在页面的 meta 标签中
- **SEO效果**: 搜索引擎可以读取到页面描述
- **社交分享**: 分享链接时显示自定义描述而不是页面内容摘要

### 功能说明

`description` 字段用于设置页面的元描述，这对SEO和社交媒体分享非常重要：

1. **SEO优化**: 搜索引擎会显示这个描述作为搜索结果的摘要
2. **社交分享**: Twitter、Facebook等平台会使用这个描述作为链接预览
3. **用户体验**: 提供页面内容的简洁概述

## 📋 当前配置

```yaml
description: 这是一个专门用于测试页面描述功能的测试页面。描述内容应该出现在页面元数据中，用于SEO优化和社交分享预览。这个描述应该简洁明了地概括页面内容。
```

## 🔍 验证方法

### 1. 查看页面源码
在浏览器中右键"查看页面源代码"，搜索：
```html
<meta name="description" content="...">
```

### 2. 检查 Open Graph 标签
查找以下标签：
```html
<meta property="og:description" content="...">
```

### 3. 社交分享测试
将页面URL分享到社交平台，检查预览描述是否正确。

## 📏 描述最佳实践

- **长度**: 150-160个字符最佳
- **内容**: 准确概括页面主要内容
- **关键词**: 包含相关搜索关键词
- **独特性**: 每个页面都应有独特的描述
